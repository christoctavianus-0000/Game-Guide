# Octopath Traveler 0 Codexes

Static reference apps for skills, characters and jobs, equipment, enemies, shops, and NPCs.

- Start at [`index.html`](index.html) for the Skill Codex.
- Use the shared navigation to open the other codexes.
- Read [`PROJECT_GUIDE.md`](PROJECT_GUIDE.md) for page behavior, data contracts, and extraction workflows.
- Run `npm run check` from the repository root, or `npm run check` from this directory, to type-check and test the app.

The pages have no runtime dependencies or build step. Source workbooks, extraction scripts, generated datasets, and assets remain in this directory.
